# 医疗后台开发方案

本文档是 `medical-admin-platform` 的有效开发方案。当前项目定位为医疗挂号运营后台，覆盖科室、医生、号源、患者、平台用户、就诊人绑定、挂号订单、订单追踪、异常处理和知识库治理。

## 1. 项目原则

- 后台先完成医疗业务闭环，再扩展复杂智能能力。
- 页面展示中文业务字段，不在主表格暴露内部 ID。
- 医生、科室、患者、就诊人、号源、订单必须显示可读中文信息。
- 表格尽量一个页面展示核心字段，避免横向滚动。
- 后端保持单体多模块结构，便于 IDEA 启动和 Maven 编译。

## 2. 项目结构

```text
medical-admin-platform/
  backend/
    medical-admin-server/
    medical-business/
    medical-system/
    medical-common/
  frontend/
    medical-admin-web/
  database/
  docs/
```

## 3. 后端模块

| 模块 | 职责 |
| --- | --- |
| `backend/medical-admin-server` | Spring Boot 启动入口、应用配置、接口聚合 |
| `backend/medical-business` | 医疗挂号、号源、医生、患者、异常处理、知识库治理 |
| `backend/medical-system` | 用户、角色、菜单、权限、字典、租户等后台基础能力 |
| `backend/medical-common` | Web、Redis、MyBatis、Sa-Token、安全、日志、Excel 等通用能力 |

后端统一包名：

```text
com.smartclinic
```

启动类：

```text
com.smartclinic.MedicalAdminApplication
```

## 4. 前端模块

| 模块 | 职责 |
| --- | --- |
| `frontend/medical-admin-web` | Vue 3 医疗运营后台 |
| `src/pages/medical` | 医疗业务页面 |
| `src/api/medical` | 医疗业务接口封装 |

## 5. 验证命令

```bash
mvn -DskipTests validate
mvn -pl backend/medical-admin-server -am -DskipTests compile
cd frontend/medical-admin-web
npm run build
```
