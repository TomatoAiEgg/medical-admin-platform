# 重构迁移说明

## 目标

将旧混合工程整理为医疗运营后台专用结构，去掉无关 AI 聊天、工作流和旧目录命名对当前项目结构的干扰。

## 当前结构

```text
medical-admin-platform/
  backend/
    medical-admin-server/
    medical-business/
    medical-system/
    medical-common/
  frontend/
    medical-admin-web/
  database/
  docs/
```

## 已完成

- Maven 根工程统一为 `medical-admin-platform`。
- 后端 Java 包名统一为 `com.smartclinic`。
- Spring Boot 入口统一为 `com.smartclinic.MedicalAdminApplication`。
- MyBatis mapper namespace、扫描包和应用配置同步到新包名。
- 通用模块目录统一为 `common-*`。
- 前端目录统一为 `frontend/medical-admin-web`。
- 文档和忽略规则改为医疗后台项目说明。
