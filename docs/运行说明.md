# 运行说明

## 环境

- JDK 17
- Maven 3.9+
- Node.js 20+
- PostgreSQL
- Redis

## 后端

IDEA 启动配置：

- Main class: `com.smartclinic.MedicalAdminApplication`
- Module classpath: `medical-admin-server`
- JDK: 17

命令行只建议用于编译验证：

```bash
mvn -pl backend/medical-admin-server -am -DskipTests compile
```

不要同时用命令行和 IDEA 常驻启动后端，避免端口占用。

## 前端

```bash
cd frontend/medical-admin-web
npm install --legacy-peer-deps
npm run dev
```

访问：

```text
http://127.0.0.1:5173/medical
```
